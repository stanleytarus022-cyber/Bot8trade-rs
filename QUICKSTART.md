# 🚀 Quick Start Guide - Bot8trade-rs\n\n## Get Started in 5 Minutes\n\n### Prerequisites\n- Rust 1.70+ (`rustup` from https://rustup.rs/)\n- MetaTrader5 installed\n- Git installed\n\n---\n\n## Step 1: Clone Repository (1 min)\n\n```bash\ngit clone https://github.com/stanleytarus022-cyber/Bot8trade-rs.git\ncd Bot8trade-rs\ngit checkout develop\n```\n\n---\n\n## Step 2: Setup Configuration (2 min)\n\n```bash\n# Copy example config\ncp .env.example .env\n\n# Edit with your settings\nnano .env  # or use your favorite editor\n```\n\n**Minimum required in .env:**\n```env\nMT5_HOST=localhost\nMT5_PORT=5005\nMT5_USERNAME=your_account_number\nMT5_PASSWORD=your_password\nAPI_KEY=your_api_key\nDATABASE_URL=sqlite://bot8trade.db\n```\n\n---\n\n## Step 3: Initialize Database (1 min)\n\n```bash\n# Create database\nsqlite3 bot8trade.db < scripts/schema.sql\n\n# Verify\nsqlite3 bot8trade.db \".tables\"\n```\n\n---\n\n## Step 4: Test Connection (1 min)\n\n```bash\n# Make MT5 WebAPI enabled first:\n# Tools → Options → Network → Enable \"API Server\" → OK → Restart MT5\n\n# Then test\nbash scripts/test-connection.sh\n```\n\n---\n\n## Step 5: Run the Bot (Already done!)\n\n### Option A: Development Mode\n```bash\ncargo run\n```\n\n### Option B: Production Mode (Recommended)\n```bash\ncargo build --release\ncargo run --release\n```\n\n### Option C: Background (Linux/Mac)\n```bash\nnohup cargo run --release > bot.log 2>&1 &\ntail -f bot.log\n```\n\n---\n\n## Expected Output\n\nYou should see:\n```\n2024-05-23 14:35:00 INFO  Starting  MetaTrader5 connection established\n2024-05-23 14:35:01 INFO  Starting main trading loop...\n2024-05-23 14:35:05 INFO  Running trading cycle...\n2024-05-23 14:35:06 INFO  Fetched market data: View active trades\nsqlite3 bot8trade.db \"SELECT * FROM active_trades;\"\n\n# View today's performance\nsqlite3 bot8trade.db \"SELECT * FROM daily_performance ORDER BY trade_date DESC LIMIT 1;\"\n\n# View logs (if running in background)\ntail -f bot.log\n```\n\n---\n\n## Stop the Bot\n\n```bash\n# If running in foreground: Press Ctrl+C\n\n# If running in background:\npkill -f \"cargo run\"\n```\n\n---\n\n## Next Steps\n\n1. **Paper Trading**: Test with demo account first\n2. **Monitor**: Watch for 24+ hours before trading real money\n3. **Adjust**: Modify risk parameters in Open MetaTrader5\n2. Go to Tools → Options → Network\n3. Check \"API Server\" is enabled\n4. Restart MT5\n5. Run test again\n\n### Error: \"Database locked\"\n```bash\nrm -f bot8trade.db-*\nsqlite3 bot8trade.db < scripts/schema.sql\n```\n\n### Error: \"Invalid API key\"\n1. Get API key from https://www.alphavantage.co/\n2. Update `.env` with correct key\n3. Restart bot\n\n---\n\n## Documentation\n\n- 📖 **Full Setup**: See [INSTALLATION.md](INSTALLATION.md)\n- 🔧 **Development**: See [DEVELOPMENT.md](DEVELOPMENT.md)\n- 🌍 **Advanced Markets**: See [ADVANCED_MARKET_INTEGRATION.md](ADVANCED_MARKET_INTEGRATION.md)\n- 📊 **MT5 Integration**: See [MT5_INTEGRATION_GUIDE.md](MT5_INTEGRATION_GUIDE.md)\n- 🎯 **Performance**: See [PERFORMANCE.md](PERFORMANCE.md)\n\n---\n\n## Key Features\n\n✅ **Real-Time Analysis**\n- Live gold price monitoring\n- Technical indicators (RSI, MACD, ATR)\n- Multi-timeframe analysis\n\n✅ **Automated Trading**\n- Auto order execution\n- Risk management\n- Stop loss & take profit\n\n✅ **Market Intelligence**\n- News sentiment analysis\n- Trend detection\n- Confidence scoring\n\n✅ **Data Persistence**\n- SQLite database\n- Trade history\n- Performance metrics\n\n---\n\n## Configuration Options\n\n| Setting | Default | Range |\n|---------|---------|-------|\n| UPDATE_INTERVAL | 300s | 60-3600s |\n| MIN_CONFIDENCE | 0.75 | 0.0-1.0 |\n| RISK_PER_TRADE | 2% | 0.5-5% |\n| MAX_DAILY_LOSS | 5% | 1-10% |\n\n---\n\n## Support\n\n- 🐛 [Report Issues](https://github.com/stanleytarus022-cyber/Bot8trade-rs/issues)\n- 💬 [Ask Questions](https://github.com/stanleytarus022-cyber/Bot8trade-rs/discussions)\n- 📚 [Read Docs](https://github.com/stanleytarus022-cyber/Bot8trade-rs/wiki)\n\n---\n\n## ⚠️ Risk Disclaimer\n\nTrading involves risk.
